# Экдизис — лист персонажа

Прототип приложения игрока (PWA).

## Состав

- `src/engine/` — движок правил: бросок d100, модификаторы, Аспекты и качели, пороги, каст, книги. Без интерфейса.
- `src/data/` — схема данных и стартовые справочники (`types.ts`, `seed.json`, `tokens.json`).
- `tests/` — тесты по «Контрольным примерам» из Ядра правил.

## Команды

```
npm install
npm test        # тесты движка
npm run typecheck
```

## Решения

- Ничья в противостоянии (равные броски при равной ступени) — переброс обеих сторон.
