# Экдизис — лист персонажа

Прототип приложения игрока (PWA).

## Состав

- `src/engine/` — движок правил: бросок d100, модификаторы, Аспекты и качели, пороги, каст, книги. Без интерфейса.
- `src/data/` — схема данных и стартовые справочники (`types.ts`, `seed.json`, `tokens.json`).
- `tests/` — тесты по «Контрольным примерам» из Ядра правил.

## Команды

```
npm install
npm test        # тесты движка
npm run typecheck
```

## Решения

- Ничья в противостоянии (равные броски при равной ступени) — переброс обеих сторон.

## Ссылка для телефона

После каждого Merge в `main` приложение публикуется на https://savyur.github.io/ecdysis-app/ (GitHub Pages). На телефоне: открыть ссылку → меню браузера → «На экран Домой».

## Как устроено

- `npm run dev` — запуск на компьютере.
- `npm run tokens` — пересобрать `src/ui/tokens.css` из `src/data/tokens.json`.
- Экран «Расчёт» (`src/screens/EngineCheck.tsx`) — временный, для проверки движка на телефоне.
